## 🩺 About the Project

Dr. Sunandan Yadav needed a professional medical website that could:
- Rank on Google for **"Best Urologist in Jaipur"**
- Build trust with patients through credentials, reviews, and clear service information
- Handle appointment inquiries via WhatsApp + phone
- Educate patients through a dedicated **Awareness Hub** (blog)
- Present sensitive men's health topics with a calm, approachable tone

This was delivered as a **complete freelance project** — from design to deployment — at ₹17,000.

---

## ✨ Features

### 🏥 Core Website
- **Hero Section** — Doctor photo, credentials (MCh, MBBS, MS), and direct "Book Appointment" CTA
- **Services Section** — 6 urology specializations with patient-friendly descriptions
  - Kidney Stone Treatment (RIRS, PCNL, URS, Lithotripsy)
  - Prostate Problems (TURP, Laser options)
  - Male Sexual Health & Andrology (confidential consultations)
  - UTI & Incontinence
  - Uro-Oncology (Kidney, Bladder, Prostate, Testicular cancer)
  - Pediatric Urology
- **Treatment Details** — Deep-dive cards with minimally invasive procedure context
- **Doctor Profile** — Education, training (RUHS SMS Jaipur, GMC Kota), and specializations
- **Patient Reviews** — 4.9/5 rating across 26 Google reviews, displayed with full testimonials
- **Awareness Hub** — 13+ educational blog articles on urology topics
- **Appointment Form** — Symptom-based inquiry with WhatsApp integration
- **Contact Section** — Address, phone, OPD timings (5–7 PM), Google Maps link

### 🔍 SEO & Performance
- `sitemap.xml` — all pages indexed for Google
- `robots.txt` — crawler access configured
- Full meta tags — title, description, keywords for urology-specific search terms
- All images in **WebP format** — ~40–70% smaller than JPEG/PNG
- RIRS procedure **image slideshow** with 5 rotating visuals
- **100+ git commits** — iterative development and refinement

### 📱 UX & Accessibility
- Fully responsive — mobile-first design for patients on smartphones
- Appointment CTA visible on every scroll position
- Sticky WhatsApp button for instant contact
- Clean navigation — About, Services, Treatments, Reviews, Blog, Contact

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 (semantic) |
| Styling | CSS3 (custom, no frameworks) |
| Interactivity | Vanilla JavaScript |
| Images | WebP (optimized, 20+ assets) |
| Deployment | Vercel |

## 🎯 What Made This Project Challenging

1. **Medical copywriting** — Required understanding of urology procedures (RIRS, PCNL, TURP, Laparoscopy) and translating clinical language into patient-friendly content
2. **Sensitive topics** — Male sexual health and andrology required a tone that is professional, private, and non-intimidating
3. **Image sourcing + optimization** — 20+ medical procedure visuals sourced and converted to WebP for performance
4. **SEO for competitive niche** — "Urologist in Jaipur" is a highly competitive keyword; required precise meta strategy and structured content
5. **RIRS slideshow** — Custom JavaScript image rotator for procedural photos without any library dependency
